Técnicas de aseguramiento de la calidad

Conoce los niveles, tipos y técnicas de pruebas de software.

Niveles de prueba

Unitarias

Verifican cada componente o función de forma aislada.

Integración

Comprueban que los módulos funcionen bien en conjunto.

Sistema

Validan el sistema completo frente a los requisitos.

Aceptación

El usuario confirma que el producto cumple lo esperado.

Tipos de prueba

Caja negra

Se evalúa el comportamiento sin conocer el código interno.

Caja blanca

Se evalúa la estructura interna y el flujo del código.

Tipo de prueba

Caja negra

Se prueba el sistema "desde afuera": se le dan datos de entrada y se revisa que la salida sea la esperada, sin mirar cómo está programado por dentro.

Técnicas más usadas

  • Partición de equivalencias: agrupar los datos que se comportan igual y probar uno de cada grupo.
  • Valores límite: probar justo en los bordes (ej: 0, 1, 100 y 101 si se aceptan de 1 a 100).
  • Tablas de decisión: probar todas las combinaciones de condiciones importantes.

Tipo de prueba

Caja blanca

Se prueba el sistema "desde adentro": se mira el código y se arman pruebas para recorrer sus instrucciones, decisiones y caminos.

Técnicas más usadas

  • Cobertura de sentencias: que cada línea de código se ejecute al menos una vez.
  • Cobertura de decisiones: que cada if se pruebe por el verdadero y por el falso.
  • Cobertura de caminos: recorrer todos los caminos posibles del código.
